## Local deployment configuration

New-machine setup: `docker-setup/README.md` (linked from the root README) covers Compose services, environment setup, local API/UI startup, and health checks.

`docker-compose.yml` runs only the PostgreSQL service, binds it to `127.0.0.1:5434`, and persists data in `sap_brim_pgdata`. `docker/postgres/init/10-create-sap-brim-ai.sh` creates the `sap_brim_ai` application role/database and vector extension only for a fresh data directory. Optional SAP web fallback uses Tavily from the FastAPI process. Previous Docker runtime checks from 2026-10-27 covered PostgreSQL and the then-configured search containers; current Docker engine/container state has not been verified after removing those search services. The old cluster bootstrap role note remains historical; do not remove or recreate database volumes.
